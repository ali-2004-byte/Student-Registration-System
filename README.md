# Cityzen Registration App

Cityzen Registration App is a user-friendly desktop application built with Python and Tkinter. It allows users to manage student registrations efficiently by storing data in an Excel sheet. The app features a simple GUI for input and retrieval of student data.

---

## Features

- **Add Student Records:** Save student details like name, class, date of birth, gender, and more into an Excel file.
- **Profile Picture Upload:** Option to upload and save a profile picture for each student.
- **Data Validation:** Ensures all mandatory fields are filled before saving the record.
- **Automatic Registration Number:** Generates unique registration numbers automatically for each student.
- **Save to Excel:** Saves all data to an Excel file (`People_data.xlsx`) for easy access and management.
- **Clear Form:** Quickly reset the input fields to add new entries.

---

## Requirements

Make sure you have the following installed on your system:

- **Python 3.7 or later**
- **Tkinter** (comes pre-installed with Python)
- **Pillow** (`pip install pillow`)
- **OpenPyXL** (`pip install openpyxl`)
